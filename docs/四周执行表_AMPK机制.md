## 应急方案

### A · p-AMPK 完全没变化（Day 7 发现）

按顺序排查，**每个只需半天**：

1. **抗体问题** —— AICAR 组有反应吗？若无，是体系问题（抗体/转膜/显影）
2. **时间窗口** —— 换 2 / 10 / 20 min 更早的点，AMPK 磷酸化可能很快
3. **基线太高** —— 延长无血清饥饿至 6 h，或换无糖培养基
4. **药物失活** —— acyl-ghrelin 降解，改用 anamorelin 或现配
5. **浓度** —— 做 ghrelin 剂量梯度（1 / 10 / 100 nM）

**若全部无效**：AMPK 故事不成立，立即转向。
备选：直接测 CD36 转位（表面生物素化或流式），
讲"ghrelin 促进 CD36 膜转位"而不依赖 AMPK。
**但 Day 10 前必须决定。**

### B · 抑制剂不阻断

| 现象 | 可能原因 | 对策 |
|---|---|---|
| Compound C 不阻断 | 浓度不够 | 提到 40 µM（心肌细胞需高浓度） |
| | 预处理时间不足 | 延长至 60–90 min |
| | 旁路激活 | 加 AMPK siRNA |
| SSO 不阻断 | 浓度/时间不足 | 提到 400 µM，延长至 30 min |
| | 下游不依赖 CD36 | 查 FATP / FABPpm |
| STO-609 不阻断 | **心肌走 CaMKII** | KN93 组应有反应（本方案已包含） |

### C · NRVM 分离失败或状态差

- 细胞量不足 → 增加乳鼠数量，或改为只做 p-AMPK WB（需样少）
- 成纤维细胞污染 → 延长差速贴壁，或加 BrdU
- 细胞不搏动 → 检查消化是否过度（缩短胰酶时间）

**底线**：若 NRVM 实在做不出来，**H9C2 数据 + 充分讨论局限**也能交差。
NRVM 是加分项，不是必需项。
