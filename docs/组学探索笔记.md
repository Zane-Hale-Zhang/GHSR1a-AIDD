## 背景

课题方向：Acyl-ghrelin / GHSR1a 调控 HFpEF 心肌代谢。
问题是：GHSR1a 在心脏里到底做什么？能否用公共转录组数据提出可检验的机制假设？

## 数据调研

GEO 上 HFpEF 心脏数据集充足，筛选出几个候选：

| 数据集 | 内容 | 样本 |
|---|---|---|
| **GSE308625** | 左心室 RNA-seq，ISO + L-NAME 诱导**非肥胖** HFpEF | n=3 vs 3 |
| **GSE307669** | 琥珀酸–GPR91–心肌代谢重编程–NAD+–缓解 HFpEF，心肌细胞特异性 Gpr91 KO | n=16 |
| GSE317489 | BCKDK 调控肥胖性心脏重构（支链氨基酸代谢） | n=9 |
| GSE285966 | 恩格列净改善肥胖糖尿病 HFpEF 小鼠心功能 | n=30 |
| GSE298173 | 人 HFpEF 循环免疫细胞特征 | n=18 |

**GSE307669 是方法论上的完美模板**：

```
琥珀酸      → GPR91  → 心肌细胞代谢重编程   ← 别人做过的
acyl-ghrelin → GHSR1a → HFpEF 心肌代谢      ← 我的课题
```

同为"循环代谢物 + G 蛋白偶联受体 + 心肌代谢"，且用**心肌细胞特异性敲除**
证明因果——这套实验设计可直接照搬用于验证 GHSR1a。

## 关键发现：GHSR 在心脏 bulk 转录组中几乎测不到

对 GSE307669（16 个心肌样本）的 FPKM 矩阵做检查：

| 基因 | 均值 FPKM | 检出率 | 说明 |
|---|---|---|---|
| **Ghsr** | **0.001** | **0/16** | 靶点本身 |
| Ghrl | 0.087 | 9/16 | ghrelin 前体 |
| Sucnr1 (GPR91) | 0.104 | 5/16 | 本研究主角 |
| Mboat4 (GOAT) | 0.008 | 0/16 | 辛酰化酶 |
| Leap2 | 0.009 | 1/16 | 内源性拮抗剂 |
| Actb | 202 | 16/16 | 管家基因 |
| Myh6 | 3085 | 16/16 | 心肌标志 |

管家基因是 Ghsr 的 **20 万倍**；同样低表达的 GPR91 也是它的 **100 倍**。
正是这 100 倍的差距，决定了 GPR91 的研究能做而 GHSR 的做不了。

**结论：不能用 bulk 心脏 RNA-seq 做 GHSR 的差异表达分析。**

## 这个负面结果催生的机制假设

三种解释，每一种都可检验：

### 假说一：细胞特异性表达（最有价值）

GHSR 可能只在心脏中某一小群细胞表达（intrinsic 心脏神经元、特定免疫细胞亚群、
内皮细胞亚群等），bulk 测序把信号稀释掉了。

**验证路径**：心脏单细胞 / 单核测序，定位 GHSR 的细胞来源。
这直接回答"GHSR 在心脏的哪里"，是机制研究的第一步。

### 假说二：ghrelin 的心脏作用不依赖心脏局部 GHSR1a

可能通过 GHSR1b、其他受体，或中枢–交感神经的间接效应实现。

若成立，则课题的机制模型需要重写——**这一条对课题影响最大，也最该优先排查。**

有意思的佐证：**Ghrl 有检出（9/16）而 Ghsr 无**。
心脏可能只是 ghrelin 的靶器官，而非"合成–作用"的完整位点。

### 假说三：疾病状态下上调

正常心脏表达低，HFpEF 时可能被诱导。

**验证路径**：用 GSE308625（HFpEF vs 对照）查 GHSR 是否上调，几分钟可出结果。

## 一个待检验的推测

GHSR1a 的组成性活性约 50%，是 GPCR 中最高的一档。
一个本底活性这么高的受体若在心脏广泛高表达，会造成持续的代谢信号。
从生理上讲，细胞可能**需要把它压得很低**才能维持代谢稳态。

若真如此，**GHSR 在心脏的低表达本身就是一种调控机制**，
而疾病状态下的表达变化可能比预期更有意义。

> 这是推测，需要数据检验，不要直接写进论文。
