# GHSR1a 在 HFpEF 心脏中的机制假设与实验设计

> 基于公共数据的分析与可照搬的实验方案。
> 分析日期：2026-09-03

---

## 一、已验证的事实

### 1.1 三个独立数据集的一致结论：GHSR 转录本在心脏 bulk 数据中测不到

| 数据集 | 组织 | 方法 | Ghsr 表达 | 检出率 |
|---|---|---|---|---|
| **GSE307669** | 小鼠心肌 | bulk RNA-seq，n=16 | FPKM 0.001 | 0/16 |
| **GSE308625** | 小鼠左心室 | bulk RNA-seq，n=6 | CPM 0.000 | **0/6** |
| **HPA v21** | 人各组织 | 单细胞 RNA | nTPM — | Not detected |

GSE308625 的分析同时确认了模型成立性（**Postn 上调 6.4 倍、Col1a1 2.8 倍、Col3a1 2.4 倍**），
排除了"数据质量差导致测不到"的可能——同一批数据里管家基因完全正常
（Actb 476–509 CPM、Myh6 4984–6319 CPM）。

**GHSR 在 HFpEF 中不上调——因为它在 HFpEF 和对照中同样测不到。**

### 1.2 但文献有相反的证据

Iglesias 等，*Cardiovascular Research* 2004（PMID 15158140）：

- RT-PCR 显示 HL-1 小鼠心肌细胞表达 ghrelin 与 GHS-R
- **GHS-R1a 在人原代心肌细胞中表达**
- **放射性配体结合实验（¹²⁵I-ghrelin）显示 HL-1 细胞表面存在组成性表达的功能性 GHS-R**
- 免疫组化确认 ghrelin 存在于 HL-1 与原代人心肌细胞胞质

这是**蛋白与功能层面**的证据，比 RNA 更接近生物学真相。

## 二、核心洞察：不要把"测不到"当成"不存在"

GSE307669 提供了一个绝佳的对照组。该研究的主角 GPR91 与 GHSR1a 同属 GPCR，
而在同一批数据中：

| 基因 | G91HFpEF | G91HFpEFSUC | MG91HFpEF（cKO） | MG91HFpEFSUC |
|---|---|---|---|---|
| **Sucnr1 (GPR91)** | 0.031 | 0.113 | **0.161** | 0.155 |
| Ghsr | 0.0015 | 0.0000 | 0.0026 | 0.0000 |
| Nppa | 350.5 | 448.4 | **1008.9** | 807.2 |

两个关键点：

**一、GPR91 的 mRNA 同样低到不可靠。** FPKM 仅 0.03–0.16，且心肌细胞特异性敲除后
数值**不降反升**（0.031 → 0.161），这违背生物学常识，说明这个量级上的数字是噪声。
**GPR91 的表达量只比 GHSR 高约 100 倍，但两者都在 bulk RNA-seq 的检测限附近。**

**二、表型数据完全可靠。** Nppa 在 cKO 组高达 1008.9（对照 350.5），
敲除 GPR91 后心衰标志物升高 2.9 倍；琥珀酸补充使其从 581 降至 193。
这些高表达基因的组间差异清晰、与论文结论一致。

### 结论

> **对于 GPCR，bulk RNA-seq 的数值不能用来判断"有没有表达"。**
> 该研究之所以能做出来，是因为他们用 **Western blot 与免疫荧光**验证蛋白，
> 而不是依赖转录组数值。

GHSR1a 完全适用同一逻辑。测不到 mRNA 是 GPCR 的常态，不是否定其功能的理由。

## 三、单细胞层面的证据（HPA v21，人）

单细胞数据（nTPM）比 bulk 灵敏，能看出细胞类型分布：

| 细胞类型 | GHSR | GHRL | MBOAT4 (GOAT) | LEAP2 | SUCNR1 (GPR91) |
|---|---|---|---|---|---|
| 垂体生长激素细胞 | **19.3** | 0.8 | 0.1 | 1.0 | 0.0 |
| **NK 细胞** | **1.8** | 3.8 | 4.1 | 3.9 | 0.1 |
| 脂肪细胞 | 0.9 | 9.6 | 2.1 | 3.4 | 0.1 |
| 血管平滑肌细胞 | 0.2 | 3.3 | 0.4 | 4.5 | 0.9 |
| **心肌细胞** | **0.1** | **13.9** | **1.5** | 1.4 | **0.0** |
| 心外膜细胞 | 0.0 | 9.1 | 18.2 | 11.4 | 0.0 |
| 巨噬细胞 | 0.1 | 9.9 | 1.1 | 3.4 | **28.9** |

数据可信度验证：同一数据集中 MYH6 = 974.1、ACTB = 199.9、TNNT2 = 198.7，量级正常。

### 三个发现

**一、GHSR 在心肌细胞确实表达（0.1），只是比垂体低近 200 倍。**
不是零——单细胞能测到微量，bulk 测不到是稀释所致。

**二、GPR91 在心肌细胞是 0.0，比 GHSR 还低，但心肌细胞特异性敲除有明确表型。**
这是决定性证据：**单细胞 RNA 的数值同样不能否定功能**。
GHSR 在心肌细胞（0.1）其实比 GPR91（0.0）"更像有表达"。

**三、心肌细胞中配体与受体严重不对称——GHRL 13.9 vs GHSR 0.1，相差 139 倍。**
且酰化酶 GOAT 有表达（1.5），说明心肌细胞**能自行产生并活化 acyl-ghrelin**。

对照垂体 somatotrophs：GHSR 19.3 / GHRL 0.8（受体高、配体低，接受循环 ghrelin）。
心肌细胞恰好相反。

## 四、机制假设（按可检验性排序）

### 假说 A · 蛋白存在但转录本极低（最可能）

GHSR1a 蛋白在心肌细胞中稳定表达，但 mRNA 拷贝数极低、且被非心肌细胞稀释。

**这是 GPCR 的普遍特征**——受体只需几十至几百个拷贝即可完成信号转导，
且蛋白半衰期远长于 mRNA。

支持证据：单细胞测得心肌细胞 GHSR = 0.1（非零）；GPR91 为 0.0 却仍有明确功能。

**验证**（成本从低到高）：
1. **qPCR**（比 RNA-seq 灵敏 100 倍以上）检测分选的心肌细胞
2. **Western blot** 检测心脏组织与分离的心肌细胞
3. **免疫荧光**定位（注意 GPCR 抗体质量参差，需验证）
4. **放射性配体结合**（¹²⁵I-ghrelin）—— Iglesias 2004 已做过，可直接引用

### 假说 A′ · 心脏是 acyl-ghrelin 的**来源**而非靶器官 ⭐ 新

单细胞数据显示心肌细胞高表达配体（GHRL 13.9）、具备酰化能力（GOAT 1.5），
却几乎不表达受体（GHSR 0.1）。这提示心脏局部存在完整的
"合成—酰化—分泌"链路，而**不一定是响应 ghrelin 的效应器官**。

若成立，课题的因果方向需要重新审视：
不是"循环 acyl-ghrelin 作用于心脏"，而可能是
"**心脏产生 acyl-ghrelin，经自分泌/旁分泌或入血作用于远隔靶点**"。

**验证**：
- 检测心脏组织与冠脉窦/外周血 acyl-ghrelin 浓度梯度（证明心脏净分泌）
- 心肌细胞特异性 **Ghrl 敲除**（而非 GHSR 敲除）的表型
- 心肌细胞条件培养基对心肌细胞/成纤维细胞的作用

**这一假说若成立，是具有原创性的**——目前文献多把心脏当作 ghrelin 的靶器官，
"心脏作为分泌源"的角度少见。

### 假说 B · 免疫细胞可能是更重要的靶点

NK 细胞 GHSR = 1.8，是心肌细胞（0.1）的 18 倍。
ghrelin 的免疫调节作用有文献支持，而 HFpEF 的炎症机制近年备受关注。

**验证**：心脏免疫细胞亚群的 GHSR 表达；髓系/淋系特异性 GHSR 敲除的表型。

### 假说 C · 心脏局部作用有限，主要经中枢–交感神经通路

ghrelin 的心脏保护效应可能主要通过中枢 GHSR1a → 交感神经张力调节实现，
而非心脏局部受体。

**验证**：
- 比较全身性 KO 与心肌细胞特异性 KO 的表型差异
- 若 cKO 无表型而全身 KO 有表型 → 支持中枢机制
- 心脏特异性过表达 GHSR1a 能否 rescue 全身 KO

## 五、可照搬的实验设计

以 GSE307669（PMID 41353145）为模板，该研究的设计极为严谨：

```
琥珀酸 → GPR91 → Gq → AMPK → NAD⁺ → 糖脂代谢重编程 → 缓解 HFpEF
```

### 4.1 原研究的设计要素

| 要素 | 具体方案 |
|---|---|
| 动物 | 雄性 C57BL/6J，8 周龄起始 |
| HFpEF 模型 | **HFD + L-NAME，12 周**（对照为普通饲料） |
| 基因型 | `Gpr91fl/fl`（对照）vs `Myh6-Cre; Gpr91fl/fl`（心肌细胞特异性 KO） |
| 干预 | **1.5% 琥珀酸饮水，12 周**（与造模同步） |
| 表型 | E/A、E/E′、**GLS**（整体纵向应变）、Tei index、LVEF；Rotarod 运动耐力；HW/TL |
| 组织学 | H&E、Masson（纤维化%）、WGA（心肌细胞横截面积）、Oil Red O、电镜（脂滴/线粒体） |
| 机制 | 转录组 GO/KEGG、**p-AMPK/AMPK**、心脏 **NAD⁺** 与 NAD⁺/NADH |
| 药理学验证 | **Gq 抑制剂 Gqi**（1 µM）证明 Gq 依赖；**Compound C**（AMPK 抑制剂）证明 AMPK 依赖 |
| Rescue | **烟酰胺 NAM**（40 mM 饮水，12 周）补充 NAD⁺，证明其为功能性下游 |
| 蛋白验证 | **Western blot + 免疫荧光**（这是关键——不依赖 mRNA） |

### 4.2 照搬至 GHSR1a

```
acyl-ghrelin → GHSR1a → Gq → ? → 心肌代谢重编程 → HFpEF
```

| 要素 | 建议方案 |
|---|---|
| 动物 | 同：雄性 C57BL/6J，8 周龄 |
| HFpEF 模型 | **HFD + L-NAME 12 周**（与该研究一致，便于横向比较）；<br>或 ISO + L-NAME（非肥胖模型，脂肪代谢背景更干净） |
| 基因型 | `Ghsr1afl/fl` vs **`Myh6-Cre; Ghsr1afl/fl`**<br>⚠️ 若假说 B 成立（GHSR 不在心肌细胞），需改用对应 Cre |
| 干预 | **acyl-ghrelin** 腹腔注射（不能用饮水，肽类会被消化）；<br>或选用 **anamorelin / macimorelin**（已上市小分子激动剂，可口服，<br>且已有 9UY3 / 9V2N 共晶结构，机制明确） |
| 表型 | 完全照搬：E/A、E/E′、GLS、Tei index、LVEF、Rotarod、HW/TL、<br>Masson、WGA、Oil Red O |
| 机制 | 转录组 + **p-AMPK/AMPK** + **NAD⁺**（GHSR1a 与 GPR91 同为 Gq 偶联，<br>下游很可能共享 AMPK–NAD⁺ 轴） |
| 药理学 | **Gq 抑制剂 Gqi** 验证 Gq 依赖（GHSR1a 主要偶联 Gq，已有 9UY3 结构支持） |
| Rescue | NAM 补充 NAD⁺ |
| **蛋白验证** | **必须做** Western blot + 免疫荧光，不可依赖 RNA-seq |

### 4.3 GHSR1a 独有的实验机会

这是你的课题能做出**区别于 GPR91 研究**的地方：

**GHSR1a 具有约 50% 的组成性活性（GPCR 中最高之一）。**

因此可以设计一个 GPR91 做不了的对照：

| 组别 | 消除的成分 | 保留的成分 |
|---|---|---|
| 野生型 | — | 基础 + 配体诱导 |
| **LEAP2 处理**（内源性拮抗剂） | 配体诱导部分 | **基础活性** |
| **反向激动剂**（如 7F83 的 1KQ） | 基础 + 配体诱导 | — |
| **GHSR1a cKO** | 全部 | — |

**比较"去除配体"与"去除受体"的表型差异，即可拆分组成性活性与配体依赖活性
各自的贡献。**

这是一个机制上真正新颖的角度——组成性活性在心脏代谢中的生理意义，
目前文献几乎是空白。

## 六、立即可做的最小验证（不需要动物实验）

按成本排序，第一步当天就能做：

1. **qPCR 预实验** —— 若有小鼠心脏组织，qPCR 灵敏度远高于 RNA-seq
2. **Western blot** —— 验证 GHSR1a 蛋白（这是决定性的，不可省略）
3. **检测心脏 acyl-ghrelin 浓度梯度** —— 冠脉窦 vs 外周血，验证假说 A′
4. **整理工具化合物清单** —— anamorelin、macimorelin（已上市激动剂）；
   [D-Lys³]-GHRP-6（拮抗剂）；LEAP2（内源性拮抗剂）；
   7F83 的 1KQ（反向激动剂，可消除组成性活性）

**决策树**：

```
第一步：qPCR / Western blot 能否检出 GHSR1a 蛋白？
│
├── 能检出 ──→ 假说 A：照搬 GSE307669 的 2×2 析因设计
│              （Myh6-Cre cKO + 激动剂 rescue + AMPK/NAD⁺ 机制）
│
└── 检不出 ──→ 转向假说 A′：测心脏 acyl-ghrelin 是否净分泌
               │
               ├── 证实净分泌 ──→ 心肌细胞特异性 Ghrl 敲除
               │                  （而非 GHSR 敲除）← 原创性最高
               │
               ├── GHSR 富集免疫细胞 ──→ 假说 B：髓系/淋系特异性敲除
               │
               └── 均无 ──→ 假说 C：比较全身 KO 与 cKO 表型差异，
                              判断是否为中枢–交感机制
```

**第一条分支最省事（有现成模板可抄），第二条最有原创性。**
建议先用 Western blot 快速判定走哪条——这一个实验决定后面半年的方向。
